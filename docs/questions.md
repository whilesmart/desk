# Questions

## Can I host Desk myself?

Yes. Start with the [local installation](installation.md), then follow the [hosting guide](hosting.md) before exposing a deployment to the internet.

## Does local installation build the applications?

No. It downloads and runs compiled container images. You do not need Go, Node.js, or application source to start a release.

## Is Desk open source?

No. Desk is free to self-host and source-available under the [source-access policy](licensing.md). It is not distributed under an open-source licence.

## Can I write my own app?

Yes. Use any backend language and integrate with CAS authentication. WhileSmart Design is recommended for the frontend. See [building apps](apps.md).

## Why can I view a workspace but not create a workpad?

Viewing and editing are separate permissions. Creating a workpad requires workspace edit access. Editing a particular folder does not grant workspace-wide creation rights. Ask a workspace administrator for the access you need, or create the pad in your personal workspace.
