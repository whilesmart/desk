# Licensing and source access

Desk is free to self-host. It is source-available, not open source.

Public releases contain compiled applications. They do not include application source, development dependencies, Git history, or source maps. Browser applications include the compiled JavaScript needed to run them.

We may provide source code access to enterprise customers such as governments and NGOs. Self-hosting enterprise customers can request access from WhileSmart through their enterprise contact. Availability and permitted use are subject to the agreement for that customer.

Downloading a compiled release does not grant access to the private source repository or an open-source licence for Desk.

Third-party components retain their own licences. Their notices and licence obligations apply independently of Desk's source-access policy.
